# User Guide

# Fabric Take-up & Thread Density Control System

## German Type Shuttle Power Loom

**Machine Model:** A125 (Internal Reference)
**Guide Version:** 1.0

---

# Welcome

This guide explains how to operate and maintain the **Fabric Take-up & Thread Density Control System** of the German Type Shuttle Power Loom.

This system is responsible for pulling the finished fabric and maintaining the correct distance between one weft thread and the next. Correct adjustment of this system ensures that the woven fabric has the required number of threads (picks) per inch.

This guide is intended for loom operators and maintenance personnel.

---

# 1. System Overview

The Fabric Take-up System controls how much woven fabric is pulled after every shuttle movement.

If the fabric is pulled too quickly, the thread spacing becomes larger.

If the fabric is pulled too slowly, the thread spacing becomes smaller.

The thread spacing is controlled by changing the **Gear A** and **Gear B** combination.

---

# 2. Main Parts

| Operator Name | Function                                                |
| ------------- | ------------------------------------------------------- |
| A2 Gear       | Receives power from the shuttle mechanism               |
| Gear A        | Primary change gear used to adjust thread spacing       |
| Gear B        | Works with Gear A to determine the fabric take-up speed |
| Gear B2       | Transfers motion to the next gear stage                 |
| Gear C        | Intermediate transmission gear                          |
| Gear C2       | Drives the final gear                                   |
| Gear D        | Rotates the fabric roller                               |
| Fabric Roller | Pulls the finished fabric forward                       |

---

# 3. How the System Works

When the machine starts:

1. The shuttle mechanism rotates **Gear A2**.
2. Gear A2 rotates **Gear A** because both are fixed on the same shaft.
3. Gear A rotates **Gear B**.
4. Gear B rotates **Gear B2**.
5. Gear B2 rotates **Gear C**.
6. Gear C rotates **Gear C2**.
7. Gear C2 rotates **Gear D**.
8. Gear D rotates the fabric roller.
9. The fabric roller pulls the woven fabric.

This continuous movement controls the spacing between threads.

# 4. Daily Inspection Before Starting

Before starting the loom, check the following:

✔ Gear teeth are clean.

✔ No broken gear teeth.

✔ No loose nuts.

✔ No excessive rust.

✔ No oil leakage.

✔ No cloth or thread wrapped around the roller.

✔ Gears rotate freely.

✔ Correct gear combination is installed.

---

# 5. During Machine Operation

Observe the woven fabric continuously.

Watch for:

* Uneven thread spacing
* Incorrect fabric density
* Distorted fabric pattern
* Abnormal gear noise
* Excessive vibration
* Roller not rotating properly

If any abnormal condition is observed, stop the machine immediately.

---

# 6. Adjusting Thread Density

The machine does not automatically control thread spacing.

The operator adjusts the spacing by replacing Gear A or Gear B.

---

## If More Threads per Inch Are Required

To produce a tighter fabric:

* Install a **larger Gear B**
* OR
* Install a **smaller Gear A**

Result:

* Fabric moves more slowly.
* More threads fit within one inch.

---

## If Fewer Threads per Inch Are Required

To produce a looser fabric:

* Install a **larger Gear A**
* OR
* Install a **smaller Gear B**

Result:

* Fabric moves faster.
* Fewer threads fit within one inch.

---

# 7. Changing a Gear

**Important:** Never change gears while the machine is running.

### Step 1

Stop the loom completely.

### Step 2

Switch OFF the motor power.

### Step 3

Wait until all moving parts stop.

### Step 4

Use the correct spanner to remove the retaining nut.

### Step 5

Remove the existing gear.

### Step 6

Install the required replacement gear.

### Step 7

Ensure the gears mesh correctly.

### Step 8

Tighten the retaining nut securely.

### Step 9

Rotate the gears manually to check smooth movement.

### Step 10

Restart the machine.

---

# 8. How to Verify the Result

After changing gears, inspect the fabric using one of the following methods.

## Method 1 – Visual Inspection

Check whether:

* Thread spacing is uniform.
* Fabric appearance is correct.
* The weave pattern is consistent.
* There are no visible defects.

---

## Method 2 – Thread Counting Lens

Use the thread counting lens.

The lens contains:

* A magnifying glass
* A fixed 1-inch measuring scale

Count the number of threads within the 1-inch scale.

Compare the result with the required thread count.

If necessary, repeat the gear adjustment.

---

# 9. Weekly Maintenance

Perform the following once every week:

* Clean all gear teeth.
* Remove lint and dust.
* Apply lubricating oil to every gear.
* Check gear alignment.
* Tighten loose nuts.
* Inspect shafts and bearings.
* Remove any wrapped fabric or thread from the roller.

---

# 10. Common Problems and Solutions

| Problem                       | Possible Cause                  | Solution                                       |
| ----------------------------- | ------------------------------- | ---------------------------------------------- |
| Threads too close together    | Gear ratio incorrect            | Increase Gear A teeth or decrease Gear B teeth |
| Threads too far apart         | Gear ratio incorrect            | Decrease Gear A teeth or increase Gear B teeth |
| Uneven thread spacing         | Wrong gear combination          | Replace Gear A or Gear B and test again        |
| Fabric pattern looks abnormal | Incorrect thread density        | Adjust gear combination                        |
| Fabric not winding            | Gear D or fabric roller problem | Inspect Gear D and roller                      |
| Gear noise                    | Lack of lubrication             | Apply oil                                      |
| Gear slipping                 | Loose retaining nut             | Tighten retaining nut                          |
| Machine vibration             | Gear misalignment               | Check gear installation                        |

---

# 11. Safety Instructions

Always follow these safety rules:

* Never touch rotating gears.
* Stop the machine before any repair.
* Disconnect motor power before replacing gears.
* Wear safety gloves when handling gears.
* Use only the correct spanner.
* Ensure all retaining nuts are tightened before restarting.
* Keep hands, clothing, and tools away from moving parts.

---

---

# 13. Operator Tips

* Record successful Gear A and Gear B combinations for each fabric type to reduce future trial and error.
* Keep spare gears organized by tooth count for quick identification.
* Clean lint regularly, as buildup can hide damage and reduce gear life.
* After every gear change, run the loom for a short distance and inspect the fabric before starting full production.
* Never assume the previous gear combination is correct for a new fabric specification.

# 14. Quick Reference

| Desired Result                      | Change Required                                                                        |
| ----------------------------------- | -------------------------------------------------------------------------------------- |
| More threads per inch (Higher PPI)  | Increase Gear B teeth **or** decrease Gear A teeth                                     |
| Fewer threads per inch (Lower PPI)  | Increase Gear A teeth **or** decrease Gear B teeth                                     |
| Incorrect spacing after gear change | Stop the machine, inspect the gear combination, and verify with a thread counting lens |
| Abnormal gear noise                 | Stop the machine and inspect lubrication, gear wear, and alignment                     |

## Important Note

This machine uses a **manual, experience-based gear selection process** rather than a fixed gear chart. Operators should verify every gear change by inspecting the woven fabric and, when precise thread density is required, use a **thread counting lens** to confirm the number of threads per inch. This process ensures consistent fabric quality and helps maintain efficient production.
