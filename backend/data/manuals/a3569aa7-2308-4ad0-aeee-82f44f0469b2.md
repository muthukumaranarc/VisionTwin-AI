# Machine Technical Manual

## Fabric Take-up & Pick Density Control Gear System

### German Type Shuttle Power Loom

**Machine Model:** A125 (Internal Reference)
**Manual Version:** 1.0
**Subsystem ID:** GT (Gear Train)

---

# 1. Introduction

This manual describes the **Fabric Take-up and Pick Density Control Gear System** used in the German Type Shuttle Power Loom.

This subsystem controls the movement of the finished fabric after each weaving cycle. By changing the gear ratio, the operator can increase or decrease the number of threads (picks) per inch according to production requirements.

Unlike modern electronic looms, this machine uses **mechanically interchangeable change gears** to adjust the fabric density.

# 3. System Purpose

The Fabric Take-up Gear System performs the following functions:

* Pulls the woven fabric forward.
* Maintains the required thread spacing.
* Controls Picks Per Inch (PPI).
* Maintains fabric quality.
* Synchronizes fabric movement with the weaving mechanism.

# 6. Working Principle

When the loom starts:

1. The shuttle mechanism drives **Gear A2**.
2. Gear A2 is fixed to the same shaft as **Gear A**, causing both to rotate together.
3. Gear A transfers rotation to Gear B.
4. Gear B rotates together with Gear B2.
5. Gear B2 drives Gear C.
6. Gear C rotates together with Gear C2.
7. Gear C2 drives Gear D.
8. Gear D rotates the fabric take-up roller.
9. The take-up roller pulls the woven fabric.
10. The pulling speed determines the distance between weft threads.

---

# 7. Gear Ratio Principle

Thread density depends primarily on the ratio between **Gear A** and **Gear B**.

## Increase Thread Density (More Threads per Inch)

Operator should:

* Increase Gear B tooth count
* OR
* Decrease Gear A tooth count

Result:

* Fabric moves slower.
* More picks fit into one inch.

---

## Decrease Thread Density (Fewer Threads per Inch)

Operator should:

* Increase Gear A tooth count
* OR
* Decrease Gear B tooth count

Result:

* Fabric moves faster.
* Larger spacing between threads.

# 9. Gear Selection Method

This machine **does not have a fixed gear selection chart**.

Operators determine the correct gear combination using:

* Experience
* Trial and Error
* Fabric inspection
* Thread counting measurement

The final gear combination depends on the required fabric specification.

---

# 10. Fabric Inspection

After changing gears, the fabric should be inspected.

### Visual Inspection

Check for:

* Uniform thread spacing
* Straight weave
* Correct fabric pattern
* No visible distortion

### Thread Counting Lens

The operator may also use a **Thread Counting Lens**.

This tool contains:

* Magnifying Lens
* Fixed One-Inch Scale

The operator counts the threads inside the one-inch scale to verify the required Picks Per Inch (PPI).

# 11. Maintenance

## Weekly Maintenance

* Remove lint and dust.
* Apply lubricating oil to all gears.
* Inspect gear teeth.
* Check shaft movement.
* Tighten retaining nuts.
* Inspect gear alignment.

---

# 12. Safety Precautions

Before servicing:

* Stop the machine completely.
* Switch OFF motor power.
* Wait until all rotating parts stop.
* Wear safety gloves.
* Use correct size spanner.
* Never replace gears while the machine is running.

# 14. Common Problems

| Problem                    | Possible Cause           | Recommended Action          |
| -------------------------- | ------------------------ | --------------------------- |
| Threads too close          | Gear ratio incorrect     | Increase A or decrease B    |
| Threads too far apart      | Gear ratio incorrect     | Increase B or decrease A    |
| Uneven thread spacing      | Wrong gear combination   | Recalculate gear selection  |
| Fabric pattern distorted   | Incorrect thread density | Adjust change gears         |
| Fabric roller not rotating | Gear D failure           | Inspect D gear              |
| Excessive gear noise       | Poor lubrication         | Apply oil                   |
| Gear slipping              | Loose retaining nut      | Tighten nut                 |
| Gear vibration             | Shaft misalignment       | Check alignment             |
| Fabric not winding         | Gear damage              | Inspect complete gear train |

# 18. Knowledge Notes for AI

* This subsystem is responsible for controlling **thread spacing (Picks Per Inch)** through mechanical gear ratios.
* Operators primarily adjust **Gear A** and **Gear B** to achieve the desired fabric density.
* Gear selection is based on **experience and trial-and-error**, not a fixed chart.
* Gear tooth counts (typically 44–50 teeth) are stamped on each gear and serve as their identification.
* After any gear change, the operator confirms the result through **visual inspection** or a **thread counting lens**.
* Any issue involving incorrect thread spacing, uneven fabric density, or abnormal take-up should prompt the AI to inspect this subsystem before considering faults elsewhere in the loom.
